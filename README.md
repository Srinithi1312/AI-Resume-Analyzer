# 🤖 AI-Powered Resume Analyzer

An interactive web application that analyzes a resume against a job description and provides a skill match score, matched skills, missing skills, and improvement suggestions.

## 📌 Features

- 📄 Paste resume content
- 💼 Paste a job description
- 🔍 Detect relevant technical skills
- 📊 Calculate a resume-job match score
- ✅ Display matched skills
- ⚠️ Identify missing skills
- 💡 Provide resume improvement suggestions
- 🖥️ Interactive web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Regular Expressions (Regex)
- NLP-inspired Text Analysis
